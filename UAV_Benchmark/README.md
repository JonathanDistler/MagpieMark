# UAV Benchmark Environment
The following folder represents the necessary components to create the UAV benchmark test - mostly in use for a single UAV. The *Benchmark_enviornment.zip* holds the representative CAD files for the benchmark environment. The more accurate base for use with the PVC is under *base_files* as it is generally more manufacturable and secure, with 3 holds used to define the only necessary constraints to fully constrain the PVC.  Similarly, the most up to date head cover with aruco tags is located under *head_cover_files*. In the design, I was assuming a marker size of 50 mm x 50 mm, with unique tags generated at [Aruco tag generator](https://chev.me/arucogen/); in which case, one would generate an Aruco tag, print it out at the intended fidelity, and then paste onto each respective head cover. 

# Bill of Material
The most accurate bill-of-materials is under *Bill_of_Materials.pdf*, with the total cost of the order of $200. The PVCs are all schedule 40, NPS 1.5". The lengths of each PVC range from roughly 1 m to 2.5 m, although the height of the PVCs can be changed without a loss of generalization to cut down on material costs. The *Benchmark_assembly_drawing.PNG* outlines where each part is located spatially, as well as the exact locations and dimensions for a more analogous representation to simulation.
